## Project Overview

This project focuses on developing and evaluating machine learning classification models to predict the likelihood of diabetes using patient health data.

The aim is to compare different machine learning approaches, identify important predictive features, optimise model hyperparameters, and evaluate model performance using cross-validation techniques.

## GitHub Repository

## Dataset

- **Dataset Name:** Pima Indians Diabetes Database
- **File Name:** `diabetes.csv`
- **Number of Records:** 768 patients
- **Number of Features:** 8
- **Target Variable:** Outcome
- **Domain:** Health

The dataset contains medical information about female patients of Pima Indian heritage and is used to investigate diabetes prediction.

**Dataset Source:**  
[Kaggle – Pima Indians Diabetes Database](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)

Originally associated with the National Institute of Diabetes and Digestive and Kidney Diseases (NIDDK).

## Project Objectives

1. Explore and understand the dataset.
2. Perform data cleaning and preprocessing.
3. Analyse relevant features and their relationships with the target variable.
4. Develop and compare at least two machine learning classification models.
5. Apply hyperparameter tuning to optimise model performance.
6. Evaluate model generalisation using cross-validation.
7. Interpret and communicate the findings.
